## ✨ Features

|                        |                                                                                                |
| :--------------------- | :--------------------------------------------------------------------------------------------- |
| 💾 **Size on disk**    | Shown in a game's library page stats bar, next to last played and playtime                     |
| 🔍 **Breakdown**       | Hover over the size to see which drive it's on, and how much is DLC, Workshop and shader cache |
| 📂 **Click through**   | Opens the game's Installed Files properties, or its folder if you turn that on in settings     |
| 🎮 **Non-Steam games** | Measured from the folder their shortcut starts in                                              |

For a non-Steam game, go to its **Properties > Installed Files** to change the folder it's measured from, recalculate its size or hide it. Its size isn't updated while it's running, and is measured again at most once every 5 minutes. Recalculate measures it straight away.

## 🚀 Get started

You need **Steam** with [**Millennium**](https://steambrew.app/). Install the plugin, and sizes show up on library pages straight away.

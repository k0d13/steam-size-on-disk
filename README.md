# Size on Disk <a href='https://ko-fi.com/X8X554X28' target='_blank'>☕</a>

A Millennium plugin that allows you to instantly see the size of a game on disk.

---

![Screenshot](.github/example.png)

## Features

- Shows a game's size on disk in its library page's stats bar
- Hover over the size to see which drive it's on, and how much of it is DLC, Workshop content and shader cache
- Click the size to open the game's Installed Files properties
- Works for non-Steam games too, measured from the folder their shortcut starts in. To change that folder, recalculate the size or hide it, go to the game's Properties → Installed Files

## Prerequisites

- [Millennium](https://steambrew.app/)
